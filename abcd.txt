IMPLEMENTATION SUMMARY: MULTI-SELECT SALES INVOICE - CREATE NEW SALES INVOICE
================================================================================
Date: 2025-11-12
Location: @src\app\sales-record\

FEATURE OVERVIEW:
-----------------
Added a new option to create a new sales invoice from selected sales invoices
in the sales-record page. Users can now select multiple sales invoices and
collect all items to create a new consolidated sales invoice.

FILES MODIFIED:
---------------
1. src/app/sales-record/sales-record.page.ts
2. src/app/sales-record/sales-record.page.html

DETAILED CHANGES:
-----------------

1. TypeScript Changes (sales-record.page.ts):
   - Added new method: createSalesInvoiceFromSelectedInvoices() at line 1644

   Method Functionality:
   - Validates that at least one invoice is selected
   - Shows loading indicator with Arabic message
   - Fetches details for all selected invoices (supports both initial and final invoices)
   - Merges duplicate items by item_id and pay_price
   - Sums quantities for duplicate items
   - Transforms items for sales page format
   - Navigates to 'folder/sales' route with merged items
   - Clears invoice selection after successful navigation
   - Handles errors gracefully with user-friendly messages

   Key Features:
   - Works with both regular sales invoices (radioVal != 3) and initial invoices (radioVal == 3)
   - Uses pay_price as the merging key (appropriate for sales invoices)
   - Preserves all item details (item_name, part_no, brand, model, etc.)
   - Includes store_id and yearId for proper context

2. HTML Changes (sales-record.page.html):
   - Added new button at line 165-169 in the action buttons section

   Button Details:
   - Label: "إنشاء فاتورة مبيعات" (Create Sales Invoice)
   - Icon: receipt-outline (distinctive from other buttons)
   - Style: primary-action (consistent with other action buttons)
   - Position: First button in the action bar (logical workflow order)

BUTTON ORDER IN ACTION BAR:
----------------------------
1. إنشاء فاتورة مبيعات (Create Sales Invoice) - NEW
2. إنشاء فاتورة شراء (Create Purchase Invoice) - EXISTING
3. إنشاء طلب شراء (Create Purchase Order) - EXISTING
4. إلغاء التحديد (Clear Selection) - EXISTING

USER WORKFLOW:
--------------
1. User navigates to sales-record page
2. User selects multiple sales invoices using checkboxes
3. Selected invoices bar appears showing count and action buttons
4. User clicks "إنشاء فاتورة مبيعات" button
5. System fetches all item details from selected invoices
6. System merges duplicate items (by item_id + pay_price)
7. System navigates to sales page with pre-filled items
8. User can review and modify the new sales invoice
9. User saves the new consolidated sales invoice

TECHNICAL DETAILS:
------------------
- Item Merging Logic: Uses Map with composite key (item_id_pay_price)
- Price Field: Uses pay_price (sales price) for both key and value
- Quantity Handling: Sums quantities for matching items
- Navigation: Uses NavigationExtras with queryParams
- Status Flag: 'newInvoFromItemsPage' to indicate pre-filled invoice
- Error Handling: Try-catch with loading dismissal and toast messages

BENEFITS:
---------
1. Consolidation: Combine multiple sales invoices into one
2. Efficiency: Quickly create bulk orders from multiple small orders
3. Consistency: Same behavior as purchase invoice creation
4. User Experience: Intuitive button placement and clear labels
5. Flexibility: Works with both regular and initial invoices
